# LOOTSHOT v3：WebGL 第一版原型实施计划

日期：2026-09-14  
依据：[v3 CrazyGames 策划](v3-crazygames-game-design.md)  
历史版本：[v2 计划](archive/v2/plan.md)  

## 1. 本轮交付

在现有 Unity 工程中完成可玩的 WebGL 原型，范围固定为 4 把现代远程武器和 12 个 Boss：

- 独立主菜单：选枪、升级火力、升级弹量、升级金币、选择 Boss、开始战斗、重置进度。
- 独立战斗界面：一次点击发射一颗子弹，没有攻击间隔和倒计时。
- 战斗开始时锁定武器、火力、弹量和金币倍率；战斗中不能升级、买枪、换枪或选关。
- 弹药归零后等待所有在途子弹结算。
- 失败保留有效伤害金币，返回主菜单后默认仍选中失败的 Boss。
- 不提供“再战”按钮。玩家从主菜单再次开始。
- 只有首次击败当前进度 Boss 才解锁并默认选中下一关。
- 玩家仍可在主菜单手动选择已通关 Boss 回刷；系统不推荐目标。
- 使用独立 v3 存档，不读取、转换或覆盖 v1/v2 存档。

## 2. 最小架构

沿用现有程序集和五个小型运行时脚本，不增加管理器层或外部依赖。

| 文件 | 职责 |
|---|---|
| `GameBalance.cs` | 4 把枪、12 个 Boss、各枪火力/弹量价格、全局金币价格 |
| `GameSession.cs` | 主菜单与战斗状态、点击发射、在途结算、金币、购买和推进 |
| `SaveStore.cs` | v3 校验、桌面文件存档、WebGL PlayerPrefs 存档 |
| `GameView.cs` | 两个界面切换、按钮绑定、子弹/命中/金币/破坏反馈 |
| `FireInput.cs` | 将战斗区左键按下转交给 `GameView.Fire` |
| `PrototypeSetup.cs` | 生成原型场景、应用默认数值、EditMode 与 WebGL 构建入口 |

同一个 Unity 场景包含 `MenuScreen` 和 `BattleScreen` 两个根节点，运行时只显示一个。它们在表现和输入上完全分离，无需为了两个界面维护两个场景。

## 3. 战斗状态

```text
Menu
  └─ StartBattle → Fighting
                       ├─ 点击 → 创建在途子弹并扣 1 发弹药
                       ├─ 子弹命中 → 扣血、发命中金币
                       ├─ 最后一发已射出 → Resolving
                       ├─ Boss 归零 → Won
                       └─ 弹药与在途子弹均归零 → Lost

Won / Lost
  └─ ReturnToMenu → Menu
```

`GameSession` 不暴露 `Retry`。从 `Won` 或 `Lost` 直接调用 `StartBattle` 必须失败，确保界面不能绕过主菜单。

## 4. 进度规则

- `highestClearedBossIndex` 表示已经首通的最远 Boss。
- `selectedBossIndex` 表示主菜单当前目标。
- 失败和中途退出均不改变这两个索引。
- 首通最前沿 Boss 后，`highestClearedBossIndex` 增加 1，并默认选中下一关。
- 回刷已通关 Boss 不推进最前沿，也不自动切换目标。
- 可选择范围是所有已通关 Boss 加上当前最前沿 Boss。

## 5. 数值与奖励

每把武器独立保存火力等级和弹量等级：

```text
当前火力 = round(基础火力 × (1 + 0.08 × 火力等级))
当前弹量 = 基础弹量 + 弹量等级
金币倍率 = 1 + 0.03 × 金币等级
```

Boss 普通收益分为 70% 有效伤害池和 30% 击败奖励。每发金币按累计有效伤害比例结算，过量伤害不产金币；首次通关奖励固定且不受金币倍率影响。

四个枪段都使用相同结构：第一关约消耗基础弹量 50%，第二关约 75%，第三关约 107%～110%，需要一到两次明确强化后通关。武器购买价格严格递增。

## 6. 交互反馈

- 按下：枪口闪光、后坐、弹量立刻减少。
- 飞行：每次点击创建独立可见子弹，多次快速点击可以同时在途。
- 命中：Boss 后仰、伤害数字、金币数字、血条残影、金币飞向栏位。
- 75%/50%/25% 生命：逐层隐藏装甲部件并增强受击幅度。
- 击败：短促停顿、Boss 大幅后仰、集中金币和彩纸反馈。
- 失败：显示差额伤害和本局保留金币，仅提供返回主菜单。

视觉对象使用简单 UI 图形和短生命周期列表。第一版不制作复杂骨骼、真实布娃娃或物理碰撞。

## 7. 存档

v3 字段：金币、当前武器、最高已购武器、每枪火力等级、每枪弹量等级、金币等级、最高已通关 Boss、当前选择 Boss。

- Windows/Editor：`lootshot-save-v3.json` 与 `.bak`。
- WebGL：PlayerPrefs 中的 v3 正式值与备份值。
- 保存时机：购买、选择、命中得金币、胜利、失败、退出和重置。
- 不保存半场 Boss 血量、剩余弹药、在途子弹或离线时间。

## 8. 验证

EditMode 必须覆盖：一击一弹、无计时、弹尽等待、失败保留收益、失败不推进、胜利才推进、无直接再战、战斗中禁止购买、每枪强化独立、3% 线性金币、固定首通奖励、v3 往返和 v1/v2 保留。

数值模拟必须覆盖 4 枪 12 关无死锁、价格递增、第三关强化门槛和不同回刷选择可继续成长。

最终使用 Unity 2022.3.51f1c1 运行 EditMode，并通过 `BuildWebGL` 输出压缩构建到 `Builds/WebGL`。

## 9. 本轮不做

- 其余 12 把枪和 36 个 Boss。
- 正式角色插画、骨骼动画、音效包和封面素材。
- 瞄准角度、随机命中、Boss 攻击、玩家生命、换弹、暴击、穿透或自动射击。
- CrazyGames SDK、广告、云存档和分析。
